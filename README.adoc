== What this state shows

A text analyzer built as two Java modules from a single POM, using Maven 4's _module source hierarchy_: a core module carrying the domain model and the analysis service, and a command-line consumer that requires it.

The build produces a *single* JAR holding both modules, each under its own directory inside the archive.
Getting one JAR per module takes extra configuration, which this state deliberately does not have yet.

== Layout

[source]
----
src/
├── net.aschemann.maven.demos.analyzer.core/    Java module: domain model + services
└── net.aschemann.maven.demos.analyzer.cli/     Java module: command-line interface
pom.xml                                         Maven 4 module source hierarchy
----

== Building

[source,bash]
----
./mvnw package
----

To run it against a text file, here its own README:

[source,bash]
----
./mvnw prepare-package
java --module-path "target/classes:target/lib" \
     --module net.aschemann.maven.demos.analyzer.cli/net.aschemann.maven.demos.analyzer.cli.AnalyzerCommand \
     README.adoc
----
