[CAUTION]
====
This branch holds no code.
It is the index of the series.

Each article has its own branch with exactly the code that article describes.
Check out the branch for the article you are reading, then build.
Building here stops with a message telling you the same thing.
====

This repository contains the companion code for a series about Java Modules with https://maven.apache.org/[Apache Maven] 4's _module source hierarchy_.

== Which branch do I want?

The states differ in what they demonstrate, not in how current they are.
There is no "latest" branch to default to, which is why this one carries nothing to build.

`blog-1-basics` is where the series starts.
`javapro-1` is not its continuation but a separate retelling, which is why the two produce different artifacts: the early branches package everything into a single JAR, `javapro-1` produces one JAR per module.

The full rendered blog lives at https://maven.aschemann.net/blog/.

== Building
